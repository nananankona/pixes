# 閲覧

## イラストビューア

作品を開くと下部バーに操作が並ぶ（右上の∧∨で開閉）。

- いいね：タップで即時反映（失敗時は元に戻る）
- DL：タップでダウンロード開始。「ダウンロード中」表示中は待機
- コメント：コメント一覧を開く。投稿もここから
- その他（…）：非公開ブックマーク・共有・リンクコピー・関連作品・ブロック

右下のボタンで自動スクロール、原寸表示の切替ができる。
「画面減光」メニューで画面を暗くできる（0〜80%。OSの輝度ではなく
アプリ内の黒レイヤー。夜間の閲覧向け）。

### スライドショー

画像の長押しメニュー → 再生ボタンで開始。前後移動・ループ・
間隔（秒）の設定は閲覧設定にある。

### 背景に設定

画像の長押しメニュー →「背景に設定」でその画像を壁紙にできる。
外観設定の背景履歴（最大10件）に残り、タップで切替・長押しで削除。

## 小説ビューア

### 読書設定

本文右下の設定ボタンから変更できる。

- フォントサイズ / 行の高さ / 段落間隔
- 自動スクロール速度
- 画面減光（イラストと共通）
- 改行文字数：長い段落を指定文字数で句点区切り表示（0で無効）。
  読み上げの区切りにも連動する
- 名前変換：置換ペア（変換前→変換後）を登録すると本文表示と
  読み上げに適用される。単発作品でも使える（夢小説向け）

### しおり

読書位置を自動保存する。次に開いたら「前回の続きから読みますか？」
と聞かれる。シリーズ物は目次ボタン（右下）から話一覧を開き、
タップでその話に移動できる。

### 読み上げ（TTS）

右下のスピーカーボタンで開始・停止。エンジンは設定で選ぶ
（VOICEVOX / CapCutサーバー / CapCut v1直結 / CapCut v2直結）。
速度・音量・話者は読書設定で変更できる。
読み上げ用に「・・・」「——」等の連続記号は読点に整形される。

### Google検索

本文の文字を選択すると、選択メニューに「Googleで検索」が出る。
タップでブラウザに検索結果を開く（選択が120文字以内の場合のみ）。

## ダウンロード済みの閲覧

「ダウンロード済み」タブの一覧から、タップで作品ページ、
「表示」ボタンでローカルビューアが開く（オフライン可）。
保存時の作品情報・コメントも一緒に残る。
