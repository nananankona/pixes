# 小説

## 画面減光

本文・イラストの閲覧画面から「画面減光」でオーバーレイの暗さを調整できる
（0〜80%。OSの輝度ではなくアプリ内の黒レイヤー）。

## 閲覧ページのボタン配置

自動スクロール・読み上げ・保存はタイトルバーのボタンに移動した。
タップでON/OFFが切り替わり、アイコンも連動する。

## しおり（続きから読む）

読書位置を自動保存する。次に開いたら「前回の続きから読みますか？」と聞かれる。
設定 → 小説設定ではない、端末ローカルの保存（同期対象外）。

## シリーズ目次

シリーズ作品の閲覧画面右下に目次ボタンが出る。タップで話一覧を開き、
タップでその話に移動できる。

## 名前変換（夢小説向け）

閲覧設定パネル → 名前変換で置換ペアを登録すると、本文表示と読み上げに
適用される。単発作品でも使える。

## 長文の分割表示

閲覧設定パネルの「改行文字数」で、長い段落を指定文字数ごとに句点区切りで
分割表示できる（0で無効）。読み上げの区切りにも連動する。

## 読み上げ（TTS）

小説ページ右下のボタンで読み上げ開始・停止。エンジンは設定で選ぶ
（VOICEVOX / CapCutサーバー / CapCut v1直結 / CapCut v2直結）。
速度・音量・話者は小説ページの設定から変更できる。
読み上げ用に「・・・」「——」等の連続記号は読点に整形される。

## Google検索

本文の文字を選択すると、選択メニューに「Googleで検索」が出る。
タップでブラウザに検索結果を開く（選択が120文字以内の場合のみ）。
