# ダウンロード

## 自動ダウンロード

設定 → ダウンロード → 「閲覧時に自動ダウンロード」で対象を選ぶ
（イラストのみ / 小説のみ / 両方）。閲覧した作品だけが保存される。
プライベートモード中は自動保存しない。

## フォルダ振り分け

ダウンロードパスの下に、設定したサブパス規則で保存される。
`ID - p番号.拡張子` などの形式が選べる。

## DL済み

「ダウンロード済み」タブで一覧表示する。50件ずつ読み込み、「さらに読み込む」で追加表示。

- 上部の検索欄でタイトル・作者・IDを絞り込める（小説は本文も対象）
- イラスト / 小説 の切替ボタンで表示を切り替える
- タップで作品ページを開く。「表示」ボタンでローカルビューアが開く
- 小説はタップで本文ビューアが開く（削除も可能）
- 「無効な項目を削除」でファイルの消えた行を掃除できる

## 收藏連動

設定 → ダウンロードで以下を有効化できる。

- 收藏時に自動保存：ブックマークしたら自動でダウンロードする
- 保存時に自動收藏：ダウンロード完了時に自動でブックマークする

## 中断からの再開

1枚ごとのファイルで中断位置から再開（HTTP Range）する。
リトライ時は既存の途中ファイルに続きから追記される。
