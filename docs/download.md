# ダウンロード

## 自動ダウンロード

設定 → ダウンロード → 「閲覧時に自動ダウンロード」で対象を選ぶ
（イラストのみ / 小説のみ / 両方）。閲覧した作品だけが保存される。
プライベートモード中は自動保存しない。

## フォルダ振り分け

ダウンロードパスの下に、設定したサブパス規則で保存される。
`ID - p番号.拡張子` などの形式が選べる。

## 小説の整理

設定 → ダウンロード →「小説フォルダ分け」で保存先を選べる
（フラット / 作者別 / シリーズ別）。
保存時に作品情報（作者・タグ・シリーズ）が sidecar に残り、
DL済み一覧の検索はタイトル・作者・タグ・本文が対象。
行には作者とタグ（最大3件）を表示する。

## 小説の詳細・閲覧ページのボタン

詳細ページに保存・公式アプリで開くボタンを追加。
閲覧ページの自動スクロール・読み上げ・保存はタイトルバーに移動した。

## DL済み

「ダウンロード済み」タブで一覧表示する。50件ずつ読み込み、「さらに読み込む」で追加表示。

- 上部の検索欄でタイトル・作者・ID・タグを絞り込める（小説は本文も対象）
- イラスト / 小説 の切替ボタンで表示を切り替える
- タップで作品ページを開く。「表示」ボタンでローカルビューアが開く
- 小説はタップで本文ビューアが開く（削除も可能）
- 「無効な項目を削除」でファイルの消えた行を掃除できる

## ブックマーク連動

設定 → ダウンロードで以下を有効化できる。

- ブックマーク時に自動保存：ブックマークしたら自動でダウンロードする
- 保存時に自動ブックマーク：ダウンロード完了時に自動でブックマークする

## 中断からの再開

1枚ごとのファイルで中断位置から再開（HTTP Range）する。
リトライ時は既存の途中ファイルに続きから追記される。
