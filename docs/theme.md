# カスタムテーマ

設定 → 外観（Appearance）で変更できる。変更は即時反映される。

## アクセントカラー

プリセット7色、または「カスタム」でRGBスライダーからHEX指定。「デフォルト」で解除。

## 背景色

背景色ドット + カスタム + デフォルト。画像なし時の下地になり、
画像あり時は画像の下に敷かれる。

## 背景画像

「選択」で画像ファイルを選ぶとアプリ内にコピーして保存される
（元のファイルを消しても大丈夫、最大10件の履歴付き）。
作品の画像表示画面で長押し →「背景に設定」からも直接設定できる。
「クリア」で解除。
不透明度スライダー（0.05〜1.0）で濃さを調整。

背景が有効な間は、ナビゲーション・カード・メニュー・ダイアログが
半透明になり、壁紙が透けて見える。

## ぼかし

背景のぼかし（0〜30）。大きめの値にすると文字が読みやすくなる。
ライトテーマで白っぽさが残る場合は背景色を濃いめにすると改善する。

## 文字シャドウ

文字とアイコンに影をつける。背景画像の上で文字が見づらい場合に有効。
影の色は「影色」で変更できる（ドット＋カスタム＋デフォルト）。

## 文字色

「文字色」で全体の文字色を変更できる（ドット＋カスタム＋デフォルト）。
ボタンやダイアログ、タイトルなどFluentテーマ全体に反映される。

## アイコン色

「アイコン色」でアイコンの色を変更できる。未設定時は文字色に連動する。

## カード不透明度

背景が有効な間、カード・メニュー・ダイアログは半透明になる。
「カード不透明度」（0.20〜1.00）で透け具合を調整できる。
値を下げるとAeroグラスのように壁紙が透ける。
